## ⚙️ Core Application Flow

1. **Entry Point** – `src/main.tsx` mounts the `<App />` component into the `#root` div defined in `index.html`.
2. **Root Component (`App.tsx`)**
   - Loads the list of applications from `src/data/apps.ts`.
   - Manages three pieces of UI state:
     - `openWindows`: which app windows are currently displayed.
     - `minimizedWindows`: which of those windows are minimized.
     - `startMenuOpen`: visibility of the Start menu.
   - Provides callbacks (`openWindow`, `closeWindow`, `minimizeWindow`, `toggleStartMenu`) that are passed down to child components.
3. **Desktop (`Desktop.tsx`)**
   - Receives the `apps` list and the subset of `openWindows` that are **not** minimized.
   - Dynamically renders the appropriate window component for each open app (e.g., `<Chrome />`, `<Notepad />`).
   - Handles double‑click on desktop icons to open an app.
4. **Taskbar (`Taskbar.tsx`)**
   - Shows a Start button, icons for each open window, and a digital clock.
   - Clicking a taskbar icon restores/minimizes the corresponding window via `onTaskbarAppClick`.
5. **Start Menu (`StartMenu.tsx`)**
   - Lists every app defined in `apps.ts`.
   - Clicking an entry invokes the `openWindow` callback supplied by `App`.
6. **Individual Apps (`src/components/Apps/*.tsx`)**
   - Each app is a self‑contained React component that mimics a classic Windows 95 program (e.g., a simple text editor, a paint canvas, a media player, etc.).
   - Apps receive `onClose` / `onMinimize` callbacks via props from the Desktop wrapper.
7. **Clippy Helper (`src/components/Clippy/`)**
   - Provides a draggable, animated “assistant” similar to the legacy Microsoft Office Clippy.
   - Exposes a service layer (`service.ts`) that can be used by any component to show contextual tips.
8. **Backend Service (`src/services/gemini.ts`)**
   - Wraps the **Google Generative AI** SDK (`@google/generative‑ai`).
   - Currently used by the *Gemini* app to generate AI‑driven content.

## 🎨 Design & Styling

- **CSS** – The project relies on a single global stylesheet (`index.css`) which includes modern design tokens (CSS variables for colours, gradients, glass‑morphism effects, and micro‑animations). Component‑specific styles are imported via CSS modules residing next to each component folder.
- **Typography** – The UI uses the *Inter* Google Font (loaded via `index.html`) for a clean, modern look while preserving the retro Windows‑95 feel through colour palettes and borders.
- **Responsive** – Though the UI mimics a fixed‑size desktop, the layout gracefully scales on smaller viewports by adjusting icon sizes and using flexbox for the taskbar.

## 📚 How the App Works (User Interaction Flow)

1. The user opens the site → `App` mounts.
2. The desktop background displays icons for each app (handled inside `Desktop`).
3. Clicking an icon (or selecting it from the Start menu) calls `openWindow(appId)` which:
   - Adds the app ID to `openWindows`.
   - Removes it from `minimizedWindows` (restoring any previously minimized instance).
   - Closes the Start menu.
4. The corresponding app component appears on the desktop. Each app includes a window header with **Close** and **Minimize** buttons that trigger `closeWindow` / `minimizeWindow`.
5. Minimized apps are hidden on the desktop but remain visible as icons on the Taskbar. Clicking the taskbar icon restores the window.
6. The **Start button** toggles the `startMenuOpen` state, revealing the list of apps.
7. The **clock** updates every second via a `setInterval` inside `Taskbar`.

## 🛠️ Extending the Project

- **Add a new app**: Create a component under `src/components/Apps/`, export it, and add its metadata to `src/data/apps.ts`. No additional routing is required because `Desktop` dynamically loads apps based on the ID.
- **Theme tweaks**: Adjust colour variables in `index.css` (e.g., `--primary`, `--background`). The UI automatically picks up the new palette.
- **Backend integration**: Implement additional API calls in `src/services/` and expose them via context or props to the relevant app components.
